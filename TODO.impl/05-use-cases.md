# 05 — Use cases

**Status:** done

`/use-cases` — the jobs. Each job: the situation, what the service
does, what the member sees, the assets that power it, and where the
demonstration lives.

1. **Answer questions from the corpus** — everyday phrasing to
   defined terms, edition-aware, cited to the clause; the citation
   opens the original at the clause. Links to the answer anatomy on
   Home (`/#what-members-see`).
2. **Decide conformance** — rules executed with the arithmetic shown
   and the standard's own violation wording; counterfactuals
   evaluated like real values. Home of the verdict playground (Vue
   island), attributed once to the reference deployment's corpus.
3. **Prove absence** — an enumeration certificate instead of a
   refusal: nodes examined, zero matches, scope stated. Static
   certificate rendering, labeled illustrative.
4. **Check any answer** — deterministic quote and object checks plus
   judged faithfulness, for answers from this service or any other.
   Home of the quote verifier (Vue island).

Roadmap band (clearly labeled, no dates): semantic edition diffs;
committee impact analysis; process walking — linking to Annealment's
frontier.
