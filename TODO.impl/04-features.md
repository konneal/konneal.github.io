# 04 — Features catalog

**Status:** done

`/features` — the complete, scannable capability catalog for the
evaluator's checklist. Three families (the annealment levels, so the
structure teaches the product):

1. **Grounded answering** — clause-cited answers; vocabulary binding;
   edition awareness; identifier understanding.
2. **Typed rendering** — tables as data; formulas as mathematics;
   figures from the original drawing; model objects served.
3. **Execution** — computed verdicts; counterfactuals; provable
   absence; answer verification; measurement gates.

Each feature card: name (plain), *what it is* (1–2 complete
sentences, positive), *in practice* (what the member experiences),
and powered-by asset tags. Tag legend up front: filled = baseline
with a Metanorma library; outlined `+` = what a further asset adds.

Cross-links: each family links to its Use cases; the intro links to
the home inventory ladder and to Annealment (which measurement
grounds the catalog).

## Acceptance

13 features shipped across 3 families; every card has ≥1 asset tag;
grep shows no "without it" constructions; page links to
/#what-you-have and /use-cases/.
