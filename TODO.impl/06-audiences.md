# 06 — Audiences

**Status:** done

`/audiences` — "what are you, and how you benefit." Four
self-identifications; each states the stakeholder's responsibility,
what changes for them, and links to their use cases:

1. **The secretariat / publisher** (the buyer) — the publication
   portfolio becomes a service; member questions stop queuing for
   expert time; institutional authority is protected because every
   answer shows its source.
2. **Members, laboratories, manufacturers, assessors** (the end
   users) — authoritative answers at any hour, computed verdicts,
   editions handled for them.
3. **Technical committees** (drafting) — today, models that are
   machine-checked consistent; on the frontier, impact analysis and
   edition diffs at the requirement level.
4. **The digital / IT team** (the implementer) — open-weight models,
   a portable design, a declared profile the organization owns, and
   gates that run on every change.

## Acceptance

Each audience section links to at least one use case; copy passes the
voice rules; nothing promises undated capability as current
(committee capabilities are marked as frontier).
