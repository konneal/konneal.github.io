# 07 — How it works

**Status:** done

`/how-it-works` — the machinery, in the public vocabulary: assets →
passes → gates.

Sections:

1. **What you bring** — the assets, each stated as structure the
   organization has already authored (Metanorma library; Pubid
   identifiers; Relaton records; Glossarist terminology; Lutaml
   models; Primmel models). Positive framing only.
2. **The annealment passes** — from publications to the index:
   corpus assembly with provenance; clause-boundary chunking;
   contextual enrichment (recorded, replayable); typed units;
   terminology and bibliographic binding; the model plane. One index
   under a declared contract; public and restricted content in
   physically separate indexes.
3. **What happens when you ask** — the seven serving stages,
   re-voiced.
4. **The gates** — golden suites with expected citations run three
   times before any promotion, paraphrase and leakage probes,
   deterministic grading wherever possible.
5. **Execution and verification** — a summary linking to the Use
   cases demonstrations.
6. **Platform** — portable design, open-weight models, no
   proprietary provider dependency; reference adapters on Cloudflare.

The suite mechanism lives here as prose: each layer of the suite
(authored, modelled, served) makes a specific range of capability
possible. OCR does not appear.
