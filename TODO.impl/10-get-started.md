# 10 — Get started

**Status:** done

`/get-started` — adoption follows what you already have. Three
profiles + one honest note + the engagement process.

- **You author in Metanorma.** You already qualify: the grounded
  answering surface with gates, identifiers served via slug codecs.
  Path: declare the profile → annealment passes → white-label
  deploy.
- **Metanorma, plus data shapes** (Pubid, Relaton, Glossarist,
  Lutaml). Each shape imports into the profile and raises its
  features: identifier steering, edition governance, terminology
  binding, served model objects.
- **Plus Primmel models.** The execution plane turns on per
  publication family: verdicts with the standard's own violation
  wording, counterfactuals, absence certificates.

Note for organizations not yet on Metanorma (one positive sentence,
link to metanorma.org): the lattice starts at authoring.

**Engagement, the same for everyone:** inventory review (your ladder,
filled in) → profile declaration (you own it) → build with gated
measurement against your corpus → white-label launch, gates on every
change thereafter.

exists; the page ends at the live reference deployment.
